# HarboR ClipShelf

HarboR 社内向けのデスクトップ常駐ツールです（Mac / Windows）。以下のアプリの「よく使う部分」を1つにまとめています。

| 元にしたアプリ | ClipShelf での機能 |
|---|---|
| Paste | 画面下部のバーに横並びのカードで出るクリップボード履歴、元のアプリへの直接貼り付け、検索・フィルタ、色付きピンボード、Paste Stack、⌘1〜9 の Quick Paste |
| Yoink | ドラッグを始めると画面の端に出てくる「シェルフ」：ファイル・画像・テキストを一時的に置き、ドラッグで取り出す（Finder と同じく移動／コピー）。スタック・ロック・復元 |
| TextSniper | 画面の範囲を選ぶと、写っている文字を読み取ってコピー（日本語・英語、完全オフライン） |
| Magnet | ウィンドウ整列：半分 / 1/4 / 1/3 / 2/3 / 最大化 / 中央 / 元に戻す / 隣のディスプレイへ |
| AutoRaise | マウスを乗せて少し待つと、そのウィンドウが前面に来る |
| Capsomnia | スリープ防止（手動・時間指定・Caps Lock 連動） |

操作方法・画面の見た目・設定項目は、Paste（6.x）と Yoink（3.6）の実際の設定項目・メニュー・公式ヘルプに合わせています。今まで Paste / Yoink を使っていた人が、使い方を変えずにそのまま使えることを目標にしています（アイコンやロゴなどの素材は独自のものです）。

社員向けのインストール手順は **[INSTALL_GUIDE.md](INSTALL_GUIDE.md)** にあります。この README は配布する人・開発する人向けです。

## 1. GitHub で管理・配布する（おすすめ）

GitHub にこのフォルダを置くと、Mac版・Windows版のインストーラを GitHub が自動で作り、「リリース」として公開します。インストール済みのアプリは起動時と6時間ごとに最新のリリースを確認し、新しい版があれば画面上部とメニューバー（タスクトレイ）に **「新しい版があります」** と表示します。社員は **「アップデート」ボタンを押すだけ** で更新できます（費用はかかりません）。

### 1-1. 最初に1回だけ：リポジトリの準備

アプリはログインせずにリリースを見に行くため、**リリースは公開リポジトリに置く必要があります**（非公開リポジトリのリリースは外から見えません）。次のどちらかを選んでください。

**パターンA（おすすめ）：ソースは非公開、配布物だけ公開**

1. 非公開リポジトリ `harbor-clipshelf` を作り、このフォルダを push します。
2. 公開リポジトリ `harbor-clipshelf-releases` を作ります（「Add a README file」にチェックして作成。中身は空でOK）。
3. GitHub の個人設定 → Developer settings → **Fine-grained personal access tokens** で、`harbor-clipshelf-releases` だけに **Contents: Read and write** を許可したトークンを作ります。
4. 非公開リポジトリの **Settings → Secrets and variables → Actions** で次の2つを登録します。
   - Variables タブ：`RELEASE_REPO` = `（組織名）/harbor-clipshelf-releases`
   - Secrets タブ：`RELEASE_TOKEN` = 手順3のトークン

**パターンB：ソースごと公開リポジトリにする**

公開リポジトリ `harbor-clipshelf` を作って push するだけです（追加設定なし）。ソースコードにパスワードや社内情報は含まれていませんが、誰でも閲覧できるようになります。

どちらの場合も、アプリがどこを確認するかはビルド時に自動で設定されます（`package.json` の `harbor.updateRepo` を手で書き換える必要はありません）。

### 1-2. 新しい版を出す

1. `package.json` の `"version"` を上げます（例：`1.1.0` → `1.2.0`）。
2. `CHANGELOG.md` のいちばん上に `## v1.2.0` を足して、変更内容を書きます（アプリの更新画面にそのまま表示されます）。
3. commit して push します。
4. GitHub の **Actions → build → Run workflow** で **「公開する」にチェック** を入れて実行します。
   （コマンド派の人は `git tag v1.2.0 && git push origin v1.2.0` でも同じです）
5. 15分ほどで Releases に `v1.2.0` が公開され、各PCのアプリに通知が出ます。

- 「公開する」にチェックせずに実行すると、ビルドだけ行います（実行結果の **Artifacts** からインストーラを取得でき、社員には通知されません）。動作確認用に使ってください。
- 同じバージョンを2回公開しようとすると止まります。バージョンを上げてから実行してください。
- 公開したリリースを GitHub 上で削除・下書きに戻すと、それより前の版が「最新」として扱われます。

### 1-3. 社員側で起きること

| | 「アップデート」を押したあと |
|---|---|
| Windows | 新しいインストーラが開きます（アプリはいったん終了）。「次へ」で進めると新しい版が起動します。 |
| Mac（アプリケーションフォルダに入れている場合） | 自動でダウンロード → 置き換え → 再起動します（数十秒）。 |
| Mac（それ以外の場所・ディスクイメージから起動している場合） | .dmg が開くので、アプリを「Applications」へドラッグして置き換えます。 |

- ダウンロードしたファイルは、リリースに記録されたチェックサム（SHA-256）と照合してから使います。壊れていた場合は使わずにエラーを表示します。
- 「この版はスキップ」を押すと、その版の通知は出なくなります（設定タブからは引き続き更新できます）。
- 設定 → アップデート で、自動確認のON/OFF・今すぐ確認・変更内容の表示ができます。
- **Mac の注意**：Apple の有料署名を使っていないため、更新後に「アクセシビリティ」「画面収録」の許可を付け直す必要がある場合があります。ウィンドウ整列などを使っている人には、更新後にアプリが案内を出します（システム設定の一覧で HarboR ClipShelf を「−」で外して、もう一度追加）。

### 1-4. 手元でインストーラを作る場合

GitHub を使わずに作ることもできます。ただし、この方法で作ったインストーラは **アップデートの確認先が未設定** になり、「新しい版があります」の通知は出ません（使う場合は `package.json` の `harbor.updateRepo` に `組織名/リポジトリ名` を書いてからビルドしてください）。

- **Mac**：`build-mac.command` をダブルクリック（Node.js LTS が必要。無ければダウンロードページが開きます）。`release/` に `.dmg` ができます。
- **Windows**：`build-windows.bat` をダブルクリック。`release\` に `.exe` ができます。
- **コマンド**：

```bash
npm ci
npm run build:mac   # macOS 上で実行 → release/*.dmg, *.zip（Intel / Apple Silicon 両対応）
npm run build:win   # Windows 上、または Mac/Linux（wine が必要）で実行 → release/*.exe（x64 / arm64）
```

Xcode や Visual Studio Build Tools がなくてもビルドできます（その場合、シェルフから取り出すときに「移動」ではなく「コピー」になります。Mac で Xcode Command Line Tools が入っていれば、`npm run build:mac` が移動用の部品も一緒に作ります）。

### 署名について

- **Mac**：Apple Developer ID での署名・公証はしていません（ad-hoc 署名のみ）。ブラウザでダウンロードした場合は初回だけ INSTALL_GUIDE.md の手順（「このまま開く」）が必要です。社員には、この確認が出ない1行インストーラ（`curl -fsSL https://raw.githubusercontent.com/hajishohei/harbor-clipshelf/main/scripts/install-mac.sh | bash`、中身は `scripts/install-mac.sh`：最新リリースの zip をチェックサム確認のうえ「アプリケーション」へ配置して起動）を案内してください。動作は `install-check` ワークフローが実際の macOS で確認します。アプリ内アップデートで入れた版では、この手順は不要です。手順や許可の付け直しをなくしたい場合は Apple Developer Program（有料）で署名・公証してください（`package.json` の `build.mac.identity` を変更）。
- **Mac の許可をアップデート後も保つ（おすすめ）**：ad-hoc 署名のままだと、アップデートのたびに macOS が「別のアプリ」とみなし、アクセシビリティ等の許可が外れます。自作の署名用証明書を GitHub の secret `MAC_SIGNING_CERT` に登録すると、ビルドのたびに同じ証明書で署名し直す（`scripts/after-sign.js`）ので、社員は最初に1回許可すれば以後は不要になります。
  1. `bash scripts/make-signing-cert.sh ~/clipshelf-cert` を実行（`MAC_SIGNING_CERT.txt` ができます）
  2. GitHub の Settings → Secrets and variables → Actions → New repository secret で、名前 `MAC_SIGNING_CERT`、値に `MAC_SIGNING_CERT.txt` の中身を貼って保存
  3. 登録後は `MAC_SIGNING_CERT.txt` を削除（この値があれば誰でも「HarboR ClipShelf」として署名できるため、共有しない）
  - 仕組みの確認は `sign-check` ワークフロー（使い捨ての証明書で署名 → 2回のビルドで同じ要件になるか → 起動）で行います。build ワークフローの「Report signature」にどちらで署名されたかが出ます。
  - 証明書に切り替えた最初の版だけは、社員側で一度「許可をやり直す」が必要です（アプリが案内します）。
- **Windows**：コード署名はしていないため、ブラウザからダウンロードした初回インストール時に SmartScreen の確認が出ます（「詳細情報 → 実行」）。

## 2. 使い方

### クリップボード（Paste と同じ）

| 操作 | Mac | Windows |
|---|---|---|
| ClipShelf を開く / 閉じる | ⇧⌘V | Ctrl+Shift+V |
| Paste Stack を開く / 閉じる | 初期設定なし（メニューから。設定で割り当て可。Paste 本家は ⇧⌘C） | 同左 |
| 前 / 次のアイテム | ← → | ← → |
| 選択を広げる / すべて選択 | ⇧← ⇧→ / ⌘A | Shift+← → / Ctrl+A |
| 先頭 / 最後のアイテム | ⌘↑ / ⌘↓ | Ctrl+↑ / Ctrl+↓ |
| 貼り付け（元のアプリへ） / 書式なしで | Return / ⇧Return | Enter / Shift+Enter |
| Quick Paste（その番号をすぐ貼り付け） | ⌘1〜9（⇧ で書式なし） | Ctrl+1〜9（Shift で書式なし） |
| コピーだけする | ⌘C | Ctrl+C |
| プレビュー | Space | Space |
| 開く / 名前変更 / 編集 / 新しいテキスト | ⌘O / ⌘R / ⌘E / ⌘N | Ctrl+O / R / E / N |
| 削除 / 取り消し | Delete / ⌘Z | Delete / Ctrl+Z |
| 検索（もう一度押すとフィルタ） / 検索と一覧の切替 | ⌘F / Tab | Ctrl+F / Tab |
| 前 / 次のピンボード | ⌘← / ⌘→ | Ctrl+← / Ctrl+→ |
| 新しいピンボード | ⇧⌘N | Ctrl+Shift+N |
| 記録の一時停止 / 再開 | ⌘T | Ctrl+T |
| 設定 / 閉じる | ⌘, / Esc | Ctrl+, / Esc |

- マウス：クリックで選択、ダブルクリックで貼り付け、⌘ / ⇧ クリックで複数選択、カードをドラッグして他のアプリへ、ピンボードのタブへドラッグで固定、右クリックでメニュー、タイトルをクリックで名前変更。
- 文字を打つとそのまま検索になります（画像の中の文字・コピー元アプリ名・ファイル名も対象）。「リンク」「画像」などの語は種類の絞り込みとして扱います。
- バーの上端をドラッグすると高さを変えられます（ダブルクリックで元の高さ）。低くするとカードが小さい表示になります。
- **直接貼り付け**：Mac は「アクセシビリティ」の許可が必要です（許可していないときは、Paste と同じく確認ダイアログを出し、クリップボードにコピーだけします）。Windows は許可不要です。設定で「クリップボードへ」に切り替えると、コピーだけにできます。
- **Paste Stack**：開いている間にコピーしたものが順番に積まれ、⌘V / Ctrl+V を押すたびに上から1つずつ貼り付けます（右上の矢印で「上に追加」に切替）。パネルのカードをドラッグして積むこともできます。

### シェルフ（Yoink と同じ）

| 操作 | Mac | Windows |
|---|---|---|
| シェルフを表示 / 隠す | F5 | Ctrl+Shift+Y（F5 はブラウザの更新と重なるため） |
| クリップボードの内容を追加 | 上のキーを2回続けて押す | 同左 |
| 直前に消した項目を戻す | 上のキーを長押し（またはメニュー） | 同左 |
| ドラッグ中にシェルフを出さない | fn を押したまま | Alt を押したまま |

- ファイルやテキストをドラッグし始めると、画面の端（初期値：左端・中央）にシェルフが出てきます。「マウスカーソルの位置に」「画面の端までドラッグしたら」にも変更できます。何も置かずにドラッグを終えると消え、置いたものがある間は表示されたままです。空になると自動で隠れます。
- 一度に複数のファイルを置くと1つの「スタック」になります（分割ボタンでばらせます）。
- 取り出すと **Finder / エクスプローラーと同じく「移動」**（別のディスクならコピー、⌥ / Ctrl でコピー）になり、取り出した項目はリストから消えます。消したくない項目は鍵ボタンでロックできます。
- 右クリック：クイックルック・移動…・コピー…・名称変更・Finder に表示・ファイルパスをコピー・共有・スタックの分割 / まとめる・最後に削除したファイルを戻す・クリップボードから追加。
- 左下の歯車：ウインドウの位置（左右 × 上 / 中央 / 下）・大きさ（デフォルト（3 項目）／自動調整（3 項目）／自動調整（最小））。上端をドラッグすると好きな位置に動かせます。
- 右下のほうき：全ての項目を消去（ロックした項目は残ります）。

### そのほかの機能（初期値）

| 操作 | Mac | Windows |
|---|---|---|
| 画面から文字を読み取る | ⇧⌘2 | Ctrl+Shift+2 |
| 左 / 右 / 上 / 下 半分 | ⌃⌥ ← → ↑ ↓ | Ctrl+Alt+ ← → ↑ ↓ |
| 1/4（左上・右上・左下・右下） | ⌃⌥ U I J K | Ctrl+Alt+ U I J K |
| 1/3（左・中央・右） | ⌃⌥ D F G | Ctrl+Alt+ D F G |
| 2/3（左・右） | ⌃⌥ E T | Ctrl+Alt+ E T |
| 最大化 / 中央へ / 元に戻す | ⌃⌥↩ / ⌃⌥C / ⌃⌥⌫ | Ctrl+Alt+Enter / C / Backspace |
| 次 / 前のディスプレイへ | ⌃⌥⌘ → ← | Ctrl+Alt+Shift+ → ← |
| スリープ防止 ON/OFF | なし（任意で設定） | なし |

### 設定

メニューバー（タスクトレイ）のアイコン →「設定…」、またはパネルで ⌘, / Ctrl+,。

- **一般**：ログイン時に開く・メニューバーに表示・効果音・外観モード
- **クリップボード履歴**：履歴を保持する期間（1日 / 1週間 / 1ヶ月 / 1年 / 無期限）・履歴を消去・貼り付け先（アクティブなアプリへ / クリップボードへ）・常にプレーンテキスト・複数貼り付けの区切り・Paste Stack の順番・記録の一時停止
- **ショートカット**：上の表のすべて（Paste の「プレーンテキストモード」「Quick Paste」の修飾キーも選択可）。ボタンを押してキーを押すだけ。他のアプリやシステムが使っている組み合わせはその場で警告します。
- **プライバシー**：無視するアプリ・一時的なコンテンツを無視・機密情報を無視（初期値 OFF＝パスワードも記録）・リンクプレビュー・画面共有中に表示
- **シェルフ**：自動で表示する / 表示のタイミング・手動表示のショートカット・無視するアプリ・位置と大きさ・ファイルの扱い（参照 / コピー）・取り出したら削除・スタックにまとめる・クイックルックのサムネイル・エイリアスを実体に置き換え
- 画面から文字を読み取る・ウィンドウ整列・フォーカス自動切替・スリープ防止・同期・アクセス権・アップデート・情報

## 3. OS の許可（Mac）

| 機能 | 必要な許可 | どこで |
|---|---|---|
| 直接貼り付け・Paste Stack | アクセシビリティ | システム設定 → プライバシーとセキュリティ → アクセシビリティ |
| 画面から文字を読み取る | 画面収録 | 同 → 画面収録 |
| ウィンドウ整列 / フォーカス自動切替 | アクセシビリティ、オートメーション（System Events） | 同 → アクセシビリティ / オートメーション |
| クリップボード履歴の記録・シェルフ・スリープ防止 | 不要 | — |

設定 →「アクセス権」に、今の許可状態と「許可する」ボタンが出ます。アプリを更新した後に効かなくなったら、一覧から一度削除して入れ直してください（署名が変わるため）。

Windows では追加の許可は不要です。フォーカス自動切替は Windows 標準の「マウスポインターを置いたウィンドウをアクティブにする」設定を使い、OFF にすると元の値に戻します。

## 4. データ・同期・プライバシー

- 保存先：各自のPCの中（`設定 → 情報 → 保存フォルダを開く`）。サーバーはなく、履歴などのデータは外部に送りません。OCR も端末内で処理します（言語データ同梱）。通信するのは、GitHub への新しい版の確認・ダウンロードと、リンクプレビュー（コピーしたリンクのページ名・画像の取得。設定で OFF 可）だけです。
- **Paste から取り込む（Mac）**：設定 → クリップボード履歴。Paste のデータベース（アプリグループコンテナ内の Core Data SQLite）を一時フォルダにコピーして読み取り専用で開き、履歴とピンボードを取り込みます。同じ項目は二重に取り込みません。読めない場合は構造（表・列名、データ形式の種類）だけをログに記録し、内容は記録しません。フルディスクアクセスが必要な場合があります。
- **パスワードも記録します（初期値）**：パスワード管理アプリが「機密」と印を付けたコピーも履歴に残ります。残したくない場合は、設定 → プライバシー →「機密情報を無視する」を ON にするか、「無視するアプリ」に追加してください。「一時的なコンテンツ」（自動生成された一時データ）は初期値で記録しません。
- **一時停止**：⌘T、またはメニューバー／タスクトレイ →「一時停止」（15分 / 1時間 / 8時間 / 24時間 / 再開するまで）。
- **履歴の保持期間**：初期値は1ヶ月（最後に使ってから）。固定したアイテムとシェルフは対象外です。以前の版から更新した場合は、履歴が消えないよう「無期限」になっています。
- **自分の端末どうしの同期**：設定で Google Drive / Dropbox / iCloud Drive などの「同期フォルダ」を選ぶと、その中の `HarboR-ClipShelf-Data` に保存し、同期アプリが他の端末に複製します。1件＝1ファイルなので競合しにくく、同じ項目を同時に編集した場合は新しい方が残ります。フォルダが一時的に見つからない間は端末内に保存し、戻ったら自動で合流します。
- **シェルフのファイル**：初期値は Yoink と同じ「元のファイルを参照」です（元のファイルを動かすと取り出せなくなり、同期もされません）。「コピーを保管」にすると、シェルフ内にコピーを持ち、同期フォルダ経由で他の端末にも届きます（512MB超とフォルダは参照）。
- 固定（ピンボード）したファイルは常にコピーを保管します。

## 5. トラブルシューティング

| 症状 | 対処 |
|---|---|
| ショートカットが効かない | 設定 → ショートカットで警告が出ていないか確認し、別のキーに変更 |
| Return で貼り付けられない（Mac） | 設定 → アクセス権でアクセシビリティを許可。許可後も駄目なら一覧から一度外して追加し直す |
| ⇧⌘V が効かない（Mac） | Paste などが起動中だと取り合いになります。アプリがお知らせを出し、設定 → ショートカットに「Paste を終了」ボタンが出ます。終了すると自動で有効になります |
| フォルダごとにアクセス確認が出る（Mac） | 設定 → アクセス権 →「フォルダへのアクセスをまとめて許可（フルディスクアクセス）」。アップデート後に再度出る場合は、一覧から一度外して追加し直す |
| シェルフが出てこない | 設定 → シェルフ →「自動的に表示する」を確認。ドラッグ元のアプリが「無視するアプリ」に入っていないか確認。Windows はドラッグ画像を出さないアプリだと検知できないので、ショートカットで表示 |
| シェルフから取り出すと移動ではなくコピーになる | 設定 → シェルフ → 詳細に「移動用の部品が含まれていない」と出ていないか確認（GitHub で作ったインストーラには含まれます） |
| Mac で「開けません」 | INSTALL_GUIDE.md の「このまま開く」手順 |
| ウィンドウ整列が効かない（Mac） | 設定タブの許可状態を確認。更新後はアクセシビリティを入れ直す |
| 画面OCRで真っ黒 / 何も読めない（Mac） | 画面収録の許可 → アプリを再起動 |
| 同期されない | 両方の端末で同じ同期フォルダを選んでいるか、同期アプリが動いているか確認 |
| 「新しい版があります」が出ない | 設定 → アップデート →「今すぐ確認」。「確認先が未設定」と出る場合は手元ビルドの版なので、GitHub のリリースから入れ直す |
| アップデートに失敗する | 通知の「ブラウザでダウンロード」から入れ直す。Mac で置き換えに失敗した場合の記録は、ログフォルダの隣の `updates/swap.log` |
| その他 | 設定タブ最下部「ログを開く」→ `main.log` を送ってもらう |

設計メモ：

- Electron 44 でクリップボードAPIが非同期・W3C形式に変わったため、すべて `clipboard.read()` / `ClipboardItem` で実装しています。ファイルは `text/uri-list`（OSのファイル形式に自動変換）で扱います。
- 他アプリのウィンドウ操作・直接貼り付け（⌘V / Ctrl+V の送信）・Caps Lock・クリップボード変更・**システム全体のドラッグ開始の検知**は、コンパイル不要な OS 標準の仕組み（macOS: JavaScript for Automation、Windows: PowerShell + user32）で行っています。ドラッグ検知は、macOS ではドラッグ用ペーストボードの変化、Windows では Explorer などが出すドラッグ画像ウィンドウ（SysDragImage）で判定します。補助プロセスが落ちても自動で再起動し、起動できない場合は機能だけを止めて設定画面に理由を表示します。
- Electron 標準のドラッグは「コピー」しかできず結果も分からないため、Yoink と同じ「移動」とドラッグ結果の取得のために小さなネイティブモジュール（`native/`）を使います。GitHub Actions で `scripts/build-native.js` がビルドし（Mac: Xcode、Windows: Visual Studio）、無い環境では自動で Electron のドラッグ（コピー）に切り替わります。
- アップデートは、GitHub の `releases/latest/download/latest.json`（CDN配信で API の回数制限を受けない）を読み、無ければ GitHub API にフォールバックします。Mac はダウンロードした zip を展開し、アプリ終了後に小さなシェルスクリプトで .app を入れ替えて再起動します（失敗したら元に戻して起動）。Windows はインストーラを起動して終了します。
- パッケージには Electron Fuses（RunAsNode 無効・asar 以外から起動しない等）を設定しています。すべての画面は遷移・新規ウィンドウを禁止し、メインプロセスへの呼び出しは同梱の画面からだけ受け付けます。
- アイコンは `scripts/make_icons.py` と `scripts/make_icns.py` で再生成できます（`assets/icon-1024.png` を差し替えてから `npm run icons`）。

### 制限事項（元アプリとの違い）

- Paste の iCloud 同期・共有ピンボード・iPhone 連携の代わりに、同期フォルダ（Google Drive 等）による自分の端末どうしの同期です。
- Yoink の Force Touch 操作、Handoff、iPhone からの読み込み、Today ウィジェット、サービスメニュー、ドラッグアウト時の JPG/PNG 代替データの提供はありません。
- Yoink は移動したファイルを追跡しますが、ClipShelf は元の場所に無くなったファイルを「見つかりません」と表示します。
- Windows のシェルフ自動表示は、ドラッグ画像を表示するアプリ（エクスプローラー・主要ブラウザなど）からのドラッグで動きます。
- 「ショートカットの長押しで復元」は OS のキーリピートに依存するため、効かない場合はメニューの「最後に削除したファイルを戻す」を使ってください。
- Magnet の「ウィンドウを画面端へドラッグして整列」はありません（キーボード操作のみ）。
- MacBook を外部ディスプレイなしで閉じた状態のスリープ防止（Capsomnia の pmset 方式）は、管理者権限が必要なため対象外です。
