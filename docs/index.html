HarboR ClipShelf のインストール

コピー履歴（Paste と同じ使い方）とファイル置き場（Yoink と同じ使い方）の社内ツール

パソコンで開いてください

このツールは Mac と Windows 用です。このページの URL をパソコンに送って開いてください。

お使いのパソコン：Mac

1行をターミナルに貼るだけでインストールできます

  1. ターミナルを開く
    ⌘ + Space を押して「ターミナル」と入力し、Return
  2. 下の1行をコピーして、ターミナルに貼り付けて Return
    curl -fsSL https://raw.githubusercontent.com/hajishohei/harbor-clipshelf/main/scripts/install-mac.sh | bash
    1〜数分でダウンロードから起動まで自動で終わります。「開発元を確認できません」などの警告は出ません。
  3. 「はじめに」の画面で許可する
    「アプリに直接貼り付ける」の「許可する」→ システム設定の「アクセシビリティ」で HarboR ClipShelf を ON。
    「フォルダへのアクセスをまとめて許可」も押しておくと、フォルダごとの確認が出なくなります。

Windows をお使いの方は

お使いのパソコン：Windows

1行を PowerShell に貼るだけでインストールできます

  1. ターミナル（PowerShell）を開く
    スタートボタンを右クリック →「ターミナル」または「Windows PowerShell」
  2. 下の1行をコピーして、貼り付けて Enter
    irm https://raw.githubusercontent.com/hajishohei/harbor-clipshelf/main/scripts/install-windows.ps1 | iex
    貼り付けは Ctrl + V（または右クリック）。x64 / ARM を自動で判別し、管理者権限なしでインストールして起動します。「PC が保護されました」の警告は出ません。
  3. 「はじめに」の画面で「使ってみる」を押す
    画面右下（タスクトレイ）にアイコンが出ます。

Mac をお使いの方は

使い方

⇧⌘VCtrl+Shift+Vコピー履歴を開く。選んで ReturnEnter で今のアプリに貼り付け
ファイルをドラッグ画面の端にシェルフが出るので、そこに置いておけます。置いたあとは右端に小さく収納されます
F5Ctrl+Shift+Yシェルフを表示 / 隠す
Paste を使っていた方設定 → クリップボード履歴 →「Paste から取り込む」で履歴とピンボードを移せます（Mac）

新しい版が出るとアプリに「新しい版があります」と表示されます。ボタンを押すだけで更新できます。
コマンドを使わずに入れたい場合は ダウンロードページ から（初回だけ OS の確認画面が出ます）。
